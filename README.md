# iching-web

**I Ching web app** — interactive web interface for consulting the I Ching with sheaf-theoretic visualizations.

## What This Gives You

- **Hexagram generation** — traditional coin or yarrow stalk methods
- **Sheaf visualization** — see the mathematical structure behind readings
- **Line transformation** — interactive changing line exploration
- **Web-based** — runs in any modern browser

## Quick Start

```bash
# Serve locally
python -m http.server 8000
```

## How It Fits

Web frontend for `iching-sheaf`. Part of the SuperInstance mathematical visualization suite alongside `dial-space-explorer` and `conservation-art`.
